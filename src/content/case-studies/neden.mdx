<CaseSection title="Understanding a line should not mean leaving the scene">
  I built Neden while learning Turkish through television. When a line was unfamiliar, I wanted to understand the expression and its grammar while keeping the dialogue in view.

Neden adds that interaction to IINA, the macOS video player I already use. Click a subtitle word for a quick meaning, or select a phrase to pause playback and open an explanation beside the video. Follow-up questions stay in the same conversation.

I owned the product design, TypeScript plugin, Swift helper, packaging, and testing in the installed player. The project is currently pre-release.

</CaseSection>

<CaseSection title="A quick meaning or a closer look" media>
  A word click opens a small card on the video. The learner chooses Google Cloud Translation or Microsoft Translator and supplies their own key. Google's lookup returns one translation; Microsoft's English dictionary can provide alternatives, with a translation fallback when no entry is available.

Selecting a phrase opens a different kind of help: natural meaning, a breakdown of the selected words, and grammar where useful. The full subtitle line and neighboring cues give the model context while the explanation stays focused on the selection.

In the scene shown here, word lookup returns “broken” for “bozuk.” In the expression “moralin bozuk,” the meaning is closer to feeling down. That difference is why I wanted both a quick lookup and contextual help.

</CaseSection>

<CaseSection title="The difficult part was fitting AI into a running player">
  <DecisionBlock title="Stream through a small native helper.">
    The inspected IINA HTTP API did not provide the incremental response path I needed. A Swift helper handles HTTPS and Server-Sent Events, while the TypeScript plugin delivers the incoming text to the sidebar. Controlled endpoints test fragmented responses, interruptions, and timeouts.
  </DecisionBlock>

<DecisionBlock title="Keep each answer attached to the right selection.">
  A new selection, track change, or different movie can make an in-flight response irrelevant.
  Explicit ownership ties each request to its player and conversation, so late output cannot
  overwrite a newer explanation. Stop leaves a partial answer visibly incomplete.
</DecisionBlock>

  <DecisionBlock title="Treat playback as part of the interaction.">
    Selecting a phrase pauses the video. Closing the panel retains the chat and resumes eligible playback. Replay line uses the selected cue without another model request. These actions have separate state transitions because stopping an answer, hiding a panel, and changing the movie mean different things.
  </DecisionBlock>
</CaseSection>

<CaseSection title="Credentials stay out of the interface">
  Requests go directly to the learner's configured providers. Word lookup sends the clicked word; phrase explanations send the selection, its cue, nearby subtitle context, and conversation turns. The video and complete subtitle file are not uploaded.

Provider keys are stored through IINA's macOS Keychain integration and are never returned to the sidebar. The streaming helper receives credentials through private pipes rather than command arguments. Model output is rendered with restricted Markdown, and subtitle files and bridge messages are validated as untrusted input.

</CaseSection>

<CaseSection title="Working in IINA, still in development">
  Neden is part of my own Turkish-learning workflow. The source is public under the MIT license, and the local package runs on the tested Apple silicon setup with macOS 27.0 and IINA 1.5.0-beta2. There is no published package release yet.

The September 2026 release check passed 81 TypeScript and DOM tests, 10 controlled Swift-helper tests, typechecking, lint, formatting, compilation, and package validation. These checks cover application behavior and failure handling.

Language accuracy needs separate review. A response can recognize an idiom while making a mistake in its grammar breakdown. Neden supports learning and follow-up questions; generated explanations still need checking.

The remaining work includes broader native interaction checks and release installation. Selectable source text requires an external UTF-8 SRT or VTT file. The tested IINA version also lacks a teardown callback when a plugin is disabled in Preferences, so Neden provides its own overlay switch to restore native subtitles safely.

</CaseSection>
