<CaseSection title="Learning Turkish in IINA">
  I use Neden while watching Turkish television in IINA, a macOS video player. Click a subtitle word for a quick meaning, or select a phrase to pause playback and open an explanation beside the video. Follow-up questions stay in the same conversation.

I designed the interface, built the TypeScript plugin and Swift helper, and handled packaging and testing in the installed player.

</CaseSection>

<CaseSection title="Word lookup and phrase explanations" media>
  A word click opens a small card on the video. The learner chooses Google Cloud Translation or Microsoft Translator and supplies their own key. Google's lookup returns one translation; Microsoft's English dictionary can provide alternatives, with a translation fallback when no entry is available.

Selecting a phrase opens the AI sidebar. The prompt asks for its natural meaning, a breakdown of the selected words, and grammar where useful. The full subtitle line and neighboring cues provide context.

In the scene shown here, word lookup returns “broken” for “bozuk.” In the expression “moralin bozuk,” the meaning is closer to feeling down.

  <ImagePlate image={wordLookup} alt="Neden word-meaning card displayed above a Turkish subtitle in IINA." />
</CaseSection>

<CaseSection title="Streaming answers during playback">
  <DecisionBlock title="A Swift helper for streaming">
    The IINA HTTP API I inspected did not deliver response text incrementally. A Swift helper handles HTTPS and Server-Sent Events, while the TypeScript plugin delivers the incoming text to the sidebar. Controlled endpoints test fragmented responses, interruptions, and timeouts.
  </DecisionBlock>

<DecisionBlock title="Discarding late responses">
  A new selection, track change, or different movie can make an in-flight response irrelevant. The
  plugin checks which player, conversation, and selection a response belongs to before displaying
  it, so an old answer cannot overwrite a newer explanation. Stop leaves a partial answer visibly
  incomplete.
</DecisionBlock>

  <DecisionBlock title="Pause, resume, and replay">
    Selecting a phrase pauses the video. Closing the panel retains the chat and can resume playback. Replay line uses the selected cue without another model request.
  </DecisionBlock>
</CaseSection>

<CaseSection title="Provider requests and saved keys">
  Requests go directly to the learner's configured providers. Word lookup sends the clicked word; phrase explanations send the selection, its cue, nearby subtitle context, and conversation turns. The video and complete subtitle file are not uploaded.

Provider keys are stored through IINA's macOS Keychain integration. Saved keys are never returned to the sidebar. The streaming helper receives credentials through private pipes rather than command arguments. Model output is rendered with restricted Markdown, and subtitle files and bridge messages are validated as untrusted input.

</CaseSection>

<CaseSection title="Pre-release status">
  The source is public under the MIT license. I tested the local package on Apple silicon with macOS 27.0 and IINA 1.5.0-beta2. There is no published package release yet.

The September 2026 release check passed 81 TypeScript and DOM tests, 10 controlled Swift-helper tests, typechecking, lint, formatting, compilation, and package validation.

During testing, one response recognized the idiom “moralin bozuk” but gave an incorrect grammar breakdown. Generated explanations still need checking.

The remaining work includes broader native interaction checks and release installation. Selectable source text requires an external UTF-8 SRT or VTT file. The tested IINA version also lacks a teardown callback when a plugin is disabled in Preferences, so Neden provides its own overlay switch to restore native subtitles safely.

</CaseSection>
