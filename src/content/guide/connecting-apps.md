## What it is

An integration is a connection between two apps that sends or updates information from one to the other. For example, with a Google Calendar integration, a booking app adds each booking to your calendar. Some integrations are built in, and you turn them on in the app's settings. Others are set up with an automation tool or written by a developer.

An API (application programming interface) is a set of rules a company publishes so other software can read and change information in its app. A developer or an automation tool uses the API to build a connection when the app's provider doesn't include a built-in one.

## When you need it

- You copy information between apps by hand.
- You choose a new app and want to send records between it and the apps you already use.
- An app has a built-in integration, but it doesn't send the information you need.

## Popular choices

- **The app's integrations page**: Most providers list the connections they include on their website or in the app's settings. Check this first.
- **An automation tool**: Zapier, Make, and n8n connect many apps without code. See the automation tools entry.
- **A custom connection**: A developer writes a small program that uses each app's API. This fits when no ready-made integration does what you need.

## What to watch for

- **Integrations that send less than you expect.** "Connects to Google Sheets" may mean a one-time export, not an update for each new sale. Check what is sent and how often.
- **APIs on higher plans only.** Some providers give API access only on more expensive plans.
- **Who maintains it.** Any connection can stop working when one of the apps changes. Decide who checks it and fixes it.
