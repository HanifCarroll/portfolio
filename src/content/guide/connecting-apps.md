## What it is

An integration is a ready-made connection between two apps. For example, a booking app with a Google Calendar integration adds each booking to your calendar. You usually turn it on in the app's settings.

An API (application programming interface) is a set of rules a company publishes so other software can read and change information in its app. A developer or an automation tool uses the API to build a connection the app doesn't offer ready-made.

## When you need it

- You copy information between apps by hand.
- You choose a new app and want it to share information with the apps you already use.
- An app offers an integration, but it doesn't send the information you need.

## Popular choices

- **The app's integrations page**: Most apps list their integrations on their website or in their settings. Check this first.
- **An automation tool**: Zapier, Make, and n8n connect many apps without code. See the automation tools entry.
- **A custom connection**: A developer writes a small program that uses each app's API. This fits when no ready-made integration does what you need.

## What to watch for

- **Integrations that send less than you expect.** "Connects to Google Sheets" may mean a one-time export, not an update for each new sale. Check what is sent and how often.
- **APIs on higher plans only.** Some apps offer their API only on more expensive plans.
- **Who maintains it.** Any connection can stop working when one of the apps changes. Decide who checks it and fixes it.
