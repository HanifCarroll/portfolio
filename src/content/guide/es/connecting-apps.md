## Qué es <!-- heading-id: what-it-is -->

Una integración es una conexión entre dos aplicaciones que envía información de una a otra o actualiza datos en una a partir de la otra. Por ejemplo, con una integración con Google Calendar, una aplicación de turnos agrega cada reserva a tu calendario. Algunas aplicaciones ya incluyen integraciones y las activás desde su configuración. Para otras, podés usar una herramienta de automatización o pedirle a un desarrollador que escriba el código.

Una API (interfaz de programación de aplicaciones) es un conjunto de reglas que una empresa publica para que otros programas puedan leer y cambiar información en su aplicación. Cuando el proveedor no incluye una integración, un desarrollador o una herramienta de automatización usa la API para crear la conexión.

## Cuándo lo necesitás <!-- heading-id: when-you-need-it -->

- Copiás información entre aplicaciones a mano.
- Elegís una aplicación nueva y querés enviar registros entre esa aplicación y las que ya usás.
- Una aplicación incluye una integración, pero no envía los datos que necesitás.

## Opciones populares <!-- heading-id: popular-choices -->

- **La página de integraciones de la aplicación**: La mayoría de los proveedores publica las conexiones que incluye en su sitio web o en la configuración de la aplicación. Revisá eso primero.
- **Una herramienta de automatización**: Con Zapier, Make y n8n podés conectar muchas aplicaciones sin escribir código. Consultá la entrada sobre herramientas de automatización.
- **Una conexión a medida**: Un desarrollador escribe un programa chico que usa la API de cada aplicación. Es una opción cuando ninguna integración disponible hace lo que necesitás.

## Qué revisar <!-- heading-id: what-to-watch-for -->

- **Integraciones que envían menos datos de los que esperás.** «Se conecta con Google Sheets» puede significar que podés hacer una sola exportación, no que la planilla se actualiza con cada nueva venta. Revisá qué datos se envían y con qué frecuencia.
- **API solo en planes más caros.** Algunos proveedores dan acceso a la API solo en los planes más caros.
- **Quién mantiene la conexión.** Cualquier conexión puede dejar de funcionar si cambia una de las aplicaciones. Definí quién la revisa y quién la arregla.
