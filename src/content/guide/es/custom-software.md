## Qué es <!-- heading-id: what-it-is -->

Una aplicación existente es una en la que cualquiera puede registrarse, como una aplicación de turnos o de contabilidad. El software a medida es una herramienta que un desarrollador arma para un solo negocio. Puede ser un formulario de pedidos que coincida con tu menú o una página que reúna las ventas de dos locales. También puede ser algo chico: una conexión entre dos aplicaciones, un programa que complete una planilla o una sola página nueva en tu sitio web.

## Cuándo lo necesitás <!-- heading-id: when-you-need-it -->

- Probaste varias aplicaciones y cada una te sirve solo para una parte del trabajo.
- Pagás por tres o cuatro aplicaciones y copiás información entre ellas todos los días.
- Tu manera de trabajar diferencia a tu negocio y tendrías que cambiarla para poder usar una aplicación de uso general.
- Necesitás un informe o una página que no pudiste obtener con ninguna de las aplicaciones que probaste.

Si podés hacer la mayor parte del trabajo con una aplicación de uso común, empezá por ahí. Compará lo que pagarías por la suscripción durante unos años con lo que cuesta armar y mantener una herramienta a medida. Cualquiera de las dos opciones puede salir menos.

## Opciones populares <!-- heading-id: popular-choices -->

- **Ajustar la configuración de una aplicación**: Podés resolver muchos problemas cambiando la configuración sin sumar otro programa.
- **Agregar automatizaciones**: Conectá las aplicaciones que ya tenés con una herramienta de automatización o con sus API.
- **Una herramienta chica a medida**: Un formulario, una página o un informe hecho para tu negocio. Muchas veces se arma para que funcione con las aplicaciones que ya usás.
- **Una aplicación a medida**: Un desarrollo más grande, como un portal para clientes o un sistema interno. Hace falta que alguien lo mantenga actualizado.

## Qué revisar <!-- heading-id: what-to-watch-for -->

- **Quién se ocupa del mantenimiento.** El software a medida necesita actualizaciones y correcciones. Acordá quién las hace y cómo las pagás.
- **De quién son el código y las cuentas.** Asegurate de que el código, el alojamiento y el dominio estén a nombre del negocio.
- **Empezá con lo mínimo.** Armá la versión más chica que resuelva el problema principal, usala y después decidí qué agregar.
